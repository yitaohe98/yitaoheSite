# 004 - Serverless guestbook comments

The original design specification, including detailed requirements and
architecture diagrams, is preserved in
[`../design/yitaohe-comments-design-doc-v1.0.docx`](../design/yitaohe-comments-design-doc-v1.0.docx).

## Decision

The `/comments/` and `/zh/comments/` pages share one anonymous guestbook backed
by a Cloudflare Pages Function and a dedicated D1 database.

Submissions require Turnstile and are limited to approximately one attempt per
minute per HMAC-derived network identity. Chinese input is translated to
English for Llama Guard moderation. The translation is not stored.

Safe comments are published immediately. Unsafe comment text is rejected
without being stored. If translation or moderation is unavailable, the comment
is stored privately as `pending` and the visitor is told that it will appear
after manual review.

The public feed uses cursor pagination ordered by creation time and comment ID.

## Consequences

- The authored website remains static and continues to be generated by Hugo.
- Only `/api/*` invokes Pages Functions.
- Comments persist independently of Hugo builds and Git deployments.
- D1, Workers AI, Turnstile, and runtime secrets must be configured separately
  for Pages production and preview environments.
- Moderation is intentionally conservative on service failures: unavailable
  moderation never publishes content automatically.
